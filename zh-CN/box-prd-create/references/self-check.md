# 交付自检（逐项）

> 从 SKILL.md 拆出（2026-10-30）。每批写完、收尾前逐项跑；一票否决项在 SKILL.md「交付自检」。

## 结构、设计系统、正文与功能清单

帧尺寸、卡宽、帧名唯一、默认图层名、禁用符号、品牌名、手打序号、编号成对这八项跑 box-figma-prd 的版式自检脚本；屏内设计系统合规跑 token 合规扫描；**其余靠人工**。

**结构与版式**

- 所有原型帧 402×872，所有说明卡宽 349
- 同一 PRD 页面内帧名唯一
- 每个屏内编号恰好出现两次
- 同一状态只有一张说明卡
- 自建节点没有默认图层名残留（**组件实例内部的默认名不算**，判定时沿父链查是否在 INSTANCE 内）
- 连线两端节点中心距离 ≤2000px
- 顶层 AABB 相交为 0，含说明卡列与下一区标题条

**设计系统合规（仅原型帧内内容）**

- 屏内所有 fills / strokes 落在颜色 token 表内；标注层节点与徽标不计入
- 屏内所有 fontSize / lineHeight / 字重落在字体 token 表内
- 英文与数字用 Manrope，中文用 Noto Sans SC
- 会话列表行、Tab 栏用设计系统库的组件实例，未自绘
- 带「背景模糊」的 S 系列 token 同时给出模糊值
- M 系列按「自己/对方」视角选对 token
- 深底屏用浅色文字，且已沿父链读实际填充验算

**说明卡正文**（对全部说明卡与功能清单描述列跑正则）

- 无色值 `#RRGGBB`
- 无颜色/字体 token ID（`A1` `B7` `S7` `Body_S_700` 一类）
- 无字号行高组合（`14/20` 一类）
- 无像素尺寸（`宽 370`、`40 × 40`、`圆角 12`）
- 无坐标（`x = 12`）
- 无对比度数值（`9.69:1`）
- 无字体名（`Noto Sans SC` / `Manrope`）
- 全文只有 `「」`，没有 `【】` 和弯引号
- 全文没有其他品牌名称
- 每张卡只有 `说明：` 一个分节，正文全是原生有序列表
- `N-` 前缀只出现在有先后顺序的校验链上
- 判断分支成对、末支有去向；出口逐行
- 提示文案逐字、载体显式
- 数字/英文与中文之间有半角空格
- 同一个量只有一处定义，其余为引用

**功能清单**

- 无 F 编号、无编号范围、无关联屏编号列
- 无全空行；未知写「待确认」，无关写「不适用」
- 每块独立功能都有对应行，与说明卡逐条对齐

## IM 合规（2026-10-30 新增）

- 命中的每个 `im-norms` 模块都读过；基线逐条对照，偏离处有 `注：` 并列入「待 Box 裁决」
