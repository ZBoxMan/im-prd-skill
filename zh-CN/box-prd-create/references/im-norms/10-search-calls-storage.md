# 搜索、音视频通话、存储与同步、其他通用

> 适用：全局与会话内搜索、音视频通话（含通话记录、来电、多人通话、屏幕共享、通话链接、画中画、通话录制）、云端/本地历史与多端同步、备份迁移、存储清理、链接预览、草稿同步、贴纸表情的 PRD 需求。证据见 evidence/10-search-calls-storage.md。

## 基线（默认遵循，置信度高）
- **[MISC-01] 全局搜索分区**：结果按类型分区（联系人/会话、群、消息记录等），每区有标题；按账号标识精确查找可找到未添加的人。必定义：各区排序、默认条数与是否可展开更多；对方隐私设置对能否被查找的影响；是否显示已删除联系人；账号标识格式不合规时的提示；会话列表广告条目是否进入搜索结果见 ADS-07。｜量级：—｜置信度：高
- **[MISC-02] 会话内搜索**：可在当前会话内按关键词搜索。必定义：群聊是否支持按发送者筛选、日期跳转是否提供（见 MISC-24）；点击结果后的落点；结果总数或「第 n 条 / 共 m 条」的展示；已撤回、已删除、已过期消息是否可被搜到。｜量级：—｜置信度：高
- **[MISC-04] 通话记录留痕**：每通通话结束在会话中留一条记录，区分结果：已接通、已拒绝、已取消、未接通；主叫与被叫看到的文案不同。必定义：未接通是否细分为未接、无应答、忙线（见 MISC-25）；已接通是否显示时长；每种结果下双方各自的文案；是否计入未读；点击是否回拨。｜量级：—｜置信度：高
- **[MISC-07] 通话门槛**：对方对本人设有通话限制时，无法发起通话，主叫收到不可通话提示。必定义：哪些情形构成限制（对方已拉黑、对方隐私设置不允许、对方未接受会话请求等）；各情形的提示文案；是否披露原因（见 MISC-26）。｜量级：—｜置信度：高
- **[MISC-08] 人数上限与满员提示**：通话有人数上限，满员时加入失败并给出明确提示。必定义：上限 {N}；各端（手机、桌面、网页）上限是否一致；一对一通话是否可升级为多人及升级后适用的上限；群成员数超过上限时发起通话如何选人；满员提示文案。｜量级：十余人至二百人，各产品口径不一｜置信度：高
- **[MISC-11] 多端同步**：同账号多端在线时，新消息实时同步到各端。必定义：已读、删除、会话状态（置顶、静音、归档等）是否同步及同步时机；冲突时以谁为准（推荐：置顶、免打扰这类开关状态以服务端最后收到的操作为准；好友申请、入群邀请这类一次性事项先处理者生效，后到的一端显示「已在其他设备处理」，见 ACC-12；不得写成后到操作静默丢弃）；新关联设备上历史可能缺失时的说明。｜量级：—｜置信度：高
- **[MISC-13] 空间不足提示**：存储空间不足时给出提示，并暂停或阻止下载、备份、迁移任务，直到清理后重试。必定义：是否分级及各级阈值与文案；被暂停任务的恢复方式。｜量级：至少一级提示｜置信度：高
- **[MISC-14] 备份是复制**：备份不移除源设备上的数据。必定义：迁移是复制（两端合并）还是移动；执行前是否预估所需空间及空间预估文案；迁移中新到消息是否包含（见必问状态）；恢复备份时，备份后已删除或已过期的消息如何处理。｜量级：—｜置信度：高
- **[MISC-16] 收藏类上限**：表情、贴纸、GIF 的收藏有数量上限，达到上限时给出提示。必定义：各类上限；达到上限时的处理（提示先删除、自动替换最早一项或引导升级付费档）与提示文案；付费档到期后超出免费上限的已收藏内容见 PTS-25。｜量级：个位数至数百｜置信度：高
- **[MISC-17] 不支持类型兜底**：本版本无法识别的消息类型显示兜底文案，会话列表摘要同样显示兜底占位，不得显示空白或乱码。必定义：兜底文案（列表与聊天页是否同一文案）；是否引导升级及升级入口。｜量级：—｜置信度：高
- **[MISC-33] 进行中的群通话可中途加入**：群内有进行中的通话时，会话内有状态提示并提供「加入」入口，成员可中途加入；满员时按 MISC-08 处理。必定义：状态提示内容（是否含参与人数、时长）与入口文案；入口对已被移出群者的状态；来电界面是否提供「忽略」；加入后的参与者展示。｜量级：—｜置信度：高
- **[MISC-36] 本方网络导致通话无法建立时明示网络原因**：本方网络不可用导致通话无法发起或建立时，提示写明是网络原因并引导检查网络，不以「无应答」「对方忙线」一类结果代替。必定义：发起前已检测到无网络时是否直接拦截、不进入呼叫界面；提示文案与载体；是否在会话中留通话记录；通话中断网的重连与挂断见必问状态「弱网通话」。｜量级：不适用｜置信度：高

## 惯例（可默认，标建议）

- **[MISC-03] 搜索历史**：保留最近搜索，可整体清空。必定义：保留条数；是否可逐条移除；清空是否二次确认；退出登录后是否清除。｜量级：本轮未取证，由 PRD 取值｜置信度：中（两家直接证据；逐条移除与清空确认只有一家证据，只在必定义）
- **[MISC-05] 来电响铃超时**：来电响铃有超时，超时后主叫端记为「无应答」、被叫端记为「未接」。必定义：超时时长 {N} 秒及是否可由服务端调整；超时后被叫端的通知与记录。｜量级：本轮未取到数值，由 PRD 取值｜置信度：中（超时机制两家直接证据；主叫记无应答、被叫记未接各两家；数值未取证）
- **[MISC-06] 通话互斥**：通话中又有来电或要发起新通话时，不并行，须用户明确确认后才结束当前通话并接听或发起新通话。必定义：确认弹窗文案与选项；被叫方未确认时对主叫的表现；第二来电的提示形态见 MISC-44。｜量级：—｜置信度：中（仅两家直接证据）
- **[MISC-09] 通话中的状态提示**：通话中对端网络不佳等状态以提示告知。必定义：提示哪些状态（对端静音、关摄像头、网络不佳、电量低）及文案与载体；本方网络不可用时能否发起通话（见 MISC-36）；弱网时是否自动降级。｜量级：—｜置信度：中（两家直接证据；对端静音、关摄像头、本方无网不可发起各只有一家证据，只在必定义）
- **[MISC-10] 权限与设备缺失**：发起或接听通话缺少必要条件时给出引导或提示，不静默失败。必定义：哪些缺失情形需提示（麦克风或摄像头权限、无摄像头设备等）；各情形的提示文案与去向（系统设置、改用语音）；权限被拒的通用写法与去设置入口见 DISC-02。｜量级：—｜置信度：中（两家直接证据，权限缺失与设备缺失各一家）
- **[MISC-15] 草稿保留**：见 UI-31（草稿的保存、恢复、清除时机与覆盖确认只在该处定义）；跨设备同步见 MISC-32，列表草稿标识见 LIST-05。
- **[MISC-12] 缓存清理与记录删除是两件事**：清理媒体缓存与删除聊天记录是不同操作；删除聊天记录前说明删除后不可恢复。必定义：存储占用的展示维度（按类别、按会话）；清理入口与确认文案；清理缓存后媒体能否重新下载（见必问状态）；已删除记录在备份中是否仍可找回的说明。｜量级：—｜置信度：中（缓存与记录分开仅两家直接证据；删除不可恢复提示三家）
- **[MISC-37] 呼叫阶段状态**：主叫侧按阶段显示通话状态，至少区分「正在呼叫」「对方响铃中」「连接中」。必定义：各阶段文案；群通话的「加入中」「重新连接中」「等待被允许加入」（若有审批）文案；对方版本过低不支持通话或视频时的提示。｜量级：不适用｜置信度：中（两家直接证据）
- **[MISC-38] 屏幕共享的发起条件**：同一通话同一时间只有一人共享屏幕，他人共享中再发起时须确认替换或不可发起；共享与本方摄像头画面互斥或让位；缺少系统屏幕录制权限时的提示与去设置入口见 DISC-02。必定义：入口位置（通话控件或「更多」）；一对一与群通话是否都支持、是否仅视频通话可用；共享整个屏幕还是可选单个窗口；群通话中谁可共享；共享中的状态提示与停止方式；对方共享时本方如何查看；共享出错的提示。｜量级：不适用｜置信度：中（各子句两家直接证据）
- **[MISC-39] 通话中设备断开或不可用的提示**：通话中摄像头或麦克风断开、不可用、未检测到时，提示具体设备与原因并给出出口（切换设备、改用语音、转到手机继续、去设置）。发起或接听时的权限与设备缺失见 MISC-10。必定义：各情形文案与出口；设备被其他应用占用时的提示；接入新设备时是否询问切换；设备恢复后是否自动恢复原状态。｜量级：不适用｜置信度：中（两家直接证据）
- **[MISC-40] 通话链接的配套（若提供）**：是否提供通话链接见 MISC-34；提供时须同时具备入会审批开关、创建者可移除或拉黑参与者、按长期未使用计算的失效期。必定义：审批开关默认值与等候中文案；被拒、被移除后的提示及能否再次申请；失效期取值与失效后文案；创建者能否删除链接、删除时进行中的通话如何处理；加入者的资料（名称、头像、号码）向谁展示，属对方能感知到什么，按必问处理。｜量级：失效期为数十天未使用｜置信度：中（两家直接证据）

## 分歧点（必问的问 Box，可默认的按推荐写并列清单）
- **[MISC-20] 历史存储模型**：选项 A：服务端保存全量历史，新设备登录即拉取，可云端检索／选项 B：仅本机保存，服务端只暂存未送达消息（量级数十天），新设备默认无历史，须从旧设备传输／选项 C：本机为主，用户主动备份或迁移到新设备（复制并合并）。取舍背景：本机为主的模型 3 家，云端全量 2 家。推荐：C，理由：隐私与数据完整——服务端不持有明文历史，同时保留找回路径；若 ZYMIX 服务端可读明文，则选项 A 可选。｜级别：必问
- **[MISC-21] 新设备历史范围**（依 MISC-20 的 B 或 C）：选项 A：无历史／选项 B：登录时可勾选导入最近一段／选项 C：全量迁移。取舍背景：登录时导入最近一段有 2 家支持。推荐：B，理由：用户理解——减少首次迁移耗时与空间占用，同时给出可选的找回。｜级别：可默认
- **[MISC-22] 自动清理**：选项 A：不自动清理任何数据／选项 B：媒体缓存按保留时长自动清理（云端或备份可重下的前提下），聊天记录不自动清理／选项 C：聊天记录也可按保留时长（量级 30 天至一年或永久）或按每会话条数永久裁剪。推荐：B，理由：隐私与数据完整——自动删除聊天记录不可恢复，应由用户显式发起；选项 C 的清理还可能同步到其他设备。｜级别：必问
- **[MISC-23] 聊天内容搜索范围**：选项 A：仅本机已有历史（含本机识别图片文字，需用户开启）／选项 B：云端全量检索。取舍背景：本机搜索 3 家，云端检索 1 家；本机搜索库在恢复备份后需重建索引。推荐：A，理由：隐私与数据完整——与 MISC-20 联动，服务端不持有明文时无法检索。｜级别：可默认
- **[MISC-24] 搜索筛选维度**：选项 A：关键词加发送者／选项 B：再加内容类型（图片、视频、文件、链接、语音）／选项 C：再加日期与会话类型。取舍背景：内容类型、日期、发送者三种筛选各两家支持。推荐：B，理由：用户理解——内容类型是常用的收窄方式。｜级别：可默认
- **[MISC-25] 忙线呈现**：选项 A：主叫看到「对方忙线中」／选项 B：主叫看到与无应答相同的结果，被叫侧记「忙线未接」。推荐：B，理由：隐私——不向主叫暴露被叫的通话状态；与唯一有证据的产品做法（A）相反，属隐私取舍。｜级别：必问
- **[MISC-26] 通话被限制时是否披露原因**：选项 A：披露（如「对方隐私设置不允许」）／选项 B：通用不可通话提示，不区分拉黑与隐私限制。推荐：B，理由：隐私——避免主叫借此探知是否被拉黑；与已取证的两家产品做法（披露限制原因）相反，属隐私取舍。｜级别：必问
- **[MISC-27] 大群发起通话的响铃**：选项 A：对全员响铃／选项 B：成员数超过阈值（量级十余人）时不对成员响铃，仅会话内状态消息，成员可自行加入（加入入口见 MISC-33）。推荐：B，理由：用户理解——避免大群通话变成全员骚扰。｜级别：可默认
- **[MISC-28] 通话中切换设备**：本轮仅一家有直接证据（低置信度）。选项 A：不支持跨设备转移，需挂断重拨／选项 B：同端内切换音频输出与摄像头／选项 C：跨设备转移通话。推荐：A 加 B，理由：隐私——跨设备转移涉及会话密钥迁移风险，且仅一家有证据；同端切换由系统能力即可。｜级别：可默认
- **[MISC-29] 一对一升级多人通话**：选项 A：不支持／选项 B：通话中可邀请他人加入，升级后适用多人上限（见 MISC-08）。推荐：B，理由：用户理解——两家直接证据均支持，未见反例。｜级别：可默认
- **[MISC-30] 数据导出冷却**：选项 A：无冷却，随时下载／选项 B：申请后设冷却期（量级数小时），并向所有设备推送提醒，期间可取消。推荐：B，理由：隐私——防止他人短暂持有已登录设备时批量导出。｜级别：可默认
- **[MISC-31] 链接预览默认与关闭**：选项 A：默认生成，用户可在隐私设置中全局关闭（发出前单条移除的证据低）／选项 B：私密或加密会话默认不生成，需用户开启／选项 C：群权限可单独禁止成员发送带预览的链接。预览由发送端还是服务端抓取见 RICH-57。推荐：B，理由：隐私——预览生成会让生成方拿到链接；选项 C 可叠加到群权限（参见 07-groups-channels.md）。｜级别：必问
- **[MISC-32] 草稿跨设备同步**：选项 A：仅本机保存／选项 B：云同步，发送后清除，并提供一键清除全部云草稿。推荐：A，理由：隐私——草稿未发送前属私人内容，不应先上传服务端；主流做法不一（一家云同步，其余未取证），推荐项不上传未发送内容，偏保守，可默认后列入「已按推荐默认」。｜级别：可默认
- **[MISC-34] 通话链接与访客**：选项 A：不支持，通话仅限账号内成员／选项 B：支持通话链接，持链接者以访客身份加入，访客可音视频与屏幕共享但不能加人、移人或发消息；访客等候期间账号内成员全部离开则通话结束。推荐：A，理由：隐私与数据完整——无账号者进入通话涉及身份核验与骚扰面；与已取证的两家产品做法（均支持通话链接，其中一家为中置信度）相反，属隐私取舍。提供通话链接时的审批、移除与失效期见 MISC-40。｜级别：可默认
- **[MISC-35] 群语音通话中升级为视频**：选项 A：群语音通话不可直接升级为视频，需结束后重新发起／选项 B：群语音通话中成员可各自开启摄像头。推荐：A，理由：隐私——避免通话中途被动进入视频场景；仅一家有证据（中置信度，只覆盖群语音通话）。一对一通话中切换视频不在本条范围，本库未取证，需要时作为未决项问 Box。｜级别：可默认
- **[MISC-41] 通话质量反馈**：选项 A：不收集／选项 B：通话结束后抽样弹出评分，可写问题、可「暂不」／选项 C：通话中或结束后提供问题分类反馈入口（音频、视频、掉线）。推荐：B，理由：可恢复——为排查弱网与设备问题留依据，抽样且可跳过，打扰小。取舍背景：B、C 各一家。｜级别：可默认
- **[MISC-42] 屏幕共享前的隐私提示**：选项 A：开始共享前提示屏幕上的通知、密码等内容会被参与者看到，对方不是联系人时追加「只与信任的人共享」／选项 B：不提示。推荐：A，理由：隐私——共享出去的画面无法撤回。取舍背景：仅一家有证据（检索摘要）。｜级别：可默认
- **[MISC-43] 群通话中静音他人**：选项 A：不支持／选项 B：参与者可把他人静音，被静音者收到「{昵称} 将你静音」，只能自己取消静音，不能被他人开麦。推荐：B，理由：可恢复——被静音者随时可自行恢复，用于处理群通话噪声。取舍背景：仅一家支持。｜级别：可默认
- **[MISC-44] 通话中收到第二个来电的提示**：选项 A：不打断当前通话，以横幅提示新来电，可选「挂断并接听」或「拒绝」／选项 B：直接按忙线处理，被叫只留未接记录。接听后是否结束当前通话见 MISC-06，主叫看到什么见 MISC-25。推荐：A，理由：用户理解——被叫可自行判断哪通更重要。取舍背景：两家提示新来电（其中一家为检索摘要），一家对主叫直接回忙线。｜级别：可默认
- **[MISC-45] 系统来电界面**：选项 A：手机端接入系统来电界面（锁屏全屏来电，与系统电话的互斥由系统处理）／选项 B：只用应用内来电界面加推送。推荐：A，理由：用户理解——锁屏来电与系统电话一致，漏接更少。是否写入系统最近通话记录属隐私默认值，按必问处理；上架地区是否允许接入未取证，按上架地区确认。取舍背景：仅一家有证据（确认已接入）。｜级别：可默认
- **[MISC-46] 视频通话画中画**：选项 A：视频通话中切到其他页面或其他应用时自动缩为画中画／选项 B：只缩为应用内浮窗，离开应用后仅保留音频／选项 C：不支持。推荐：A，理由：用户理解——通话中常需查看会话或其他应用；系统未允许画中画时按 B 处理。取舍背景：仅一家有证据（检索摘要）。｜级别：可默认
- **[MISC-47] 通话录制**：选项 A：不提供／选项 B：提供，开始前确认，录制中全体参与者可见录制标识，文件只保存在发起者处。推荐：A，理由：隐私——录制他人语音需全体知情，平台规则要求显式同意与清晰提示；仅一家在群语音中提供录制，另一家明确不录制。｜级别：必问

## 必问状态（本模块专属，补充通用状态矩阵）
- 对方已拉黑/已注销：通话是否可发起；通话记录系统消息保留否；搜索结果里该联系人如何显示。
- 已退群或被移出群/群已解散：群通话中的人被移出时通话是否中断；已退群后会话内搜索是否仍可搜到退群前的消息。
- 多端：另一台设备已接听来电时，本机停止响铃并记录「已在其他设备接听」还是记为未接；另一台设备已清理缓存或已删除消息后搜索结果。
- 离线被叫：来电推送延迟或失败时，主叫看到什么；离线期间错过的来电在上线后何时补记录。
- 弱网通话：何时提示、何时降级为语音、何时自动挂断；重连后的计时是否连续。
- 通话中权限被收回：麦克风或摄像头被系统关闭时的提示与是否自动静音。
- 搜索结果对应的消息已撤回、已删除、已过期：结果是否消失；点击后的落点。
- 迁移或备份进行中：新到的消息、网络中断、切到后台、空间耗尽、被其他任务互斥时的行为与恢复。
- 备份恢复后：备份之后已删除、已撤回或已过期的消息是否重现；本机搜索库重建期间，搜索结果不完整时是否提示。
- 关联设备或新设备：历史比手机端缺失时，用户看到什么说明；删除、清空是否同步到所有在线设备。
- 进行中的群通话：满员、已被移出群、已被拉黑时「加入」入口的状态；访客在等候时账号内成员全部离开（若选 MISC-34 的 B）。
- 清理缓存后再点击已清理的媒体：能否重新下载；云端已过期时的提示。
- 链接预览抓取失败、超时、链接已失效：消息仍可发出，显示无预览；转发或引用时预览是否保留。
- 草稿所引用的消息已被撤回或删除：草稿是否保留、引用卡片如何显示。
- 含特定内容的消息（贴纸、投票、联系人名片、支付）：可编辑、可转发、可撤回的限制是否逐项写明（支付类见 PAY-07）。
- 群与单聊差异：通话人数上限、响铃规则、通话记录文案是否分别定义。
- 屏幕共享中：共享者断网、切后台、被来电打断、被移出群；共享中有人加入；共享中系统录屏权限被收回。
- 通话中接到系统电话：接听后应用内通话保留、挂起还是结束；后台或锁屏时麦克风被系统静音的提示。
- 通话链接（若提供）：链接已失效或被删除、创建者不在通话中、等候时通话已结束、被拒后再次申请。

## 反模式
| 泛写/错写 | 正写 | 原因 |
|---|---|---|
| 「支持搜索聊天记录」 | 写搜索范围（本机或云端）、分区、筛选维度、已撤回与已删除消息的处理、跳转落点 | 范围不明，与历史存储模型冲突 |
| 「通话结束后显示通话记录」 | 分结果（已接通、未接、已拒绝、已取消、无应答、忙线）写双方文案、是否回拨、是否计未读 | 双方视角文案缺失 |
| 「来电超时自动挂断」 | 写超时秒数、超时后双方的记录与通知 | 数值与去向缺失 |
| 「通话中收到新来电」 | 写确认弹窗文案、选项、未确认时主叫表现 | 并发通话处理缺失 |
| 「支持多人通话」 | 写人数上限、满员提示、升级路径、响铃规则 | 上限与大群骚扰未定义 |
| 「支持备份与迁移」 | 写复制还是移动、空间预估、进行中新消息、账号归属校验、中断恢复 | 数据完整性与恢复路径缺失 |
| 「清理存储」 | 区分缓存与记录，写后果文案与是否可恢复 | 误删不可恢复内容 |
| 「链接自动显示预览」 | 写默认状态、谁生成、失败态、关闭入口 | 隐私泄露与失败态缺失 |
| 「草稿自动保存」 | 写保存时机、清除条件、是否跨设备、覆盖确认 | 草稿残留或丢失 |
| 「支持屏幕共享」 | 写同时共享人数、与摄像头的关系、权限缺失引导、停止方式、共享前提示 | 共享资格与隐私提示缺失 |
| 「通话中显示网络状态」 | 区分本方与对方，写各阶段文案与本方断网时的结果 | 用户无法判断问题出在哪一方 |

## 校准样例
最易写泛的功能：来电界面的「接听」按钮。本例没有必问项：其他设备已接听时的提示、响铃超时时长、摄像头权限缺失时改用语音都按推荐写成正文，卡内数值为示意，实际取值由业务定，并在交付稿「已按推荐默认」逐条列出。

说明：
1. 来电响铃中，按钮「接听」亮起
2. 点击后进行以下判断：
   a. 1-来电状态校验：该来电是否仍可接听
      i. 主叫已取消：来电界面关闭，toast 提示：「对方已取消」，流程结束
      i. 本账号其他设备已接听：本机停止响铃，来电界面关闭，toast 提示：「已在其他设备接听」，本机通话记录记为「已在其他设备接听」，流程结束
      i. 仍可接听：进入下一个判断
   a. 2-麦克风权限判断：本机麦克风权限是否已授权
      i. 未授权：弹窗提示：「需要麦克风权限才能通话」，按钮「去设置」「取消」；点击「去设置」：跳转系统设置；点击「取消」：弹窗关闭，回到来电界面
      i. 已授权：进入下一个判断
   a. 3-摄像头权限判断：视频来电时本机摄像头权限是否已授权
      i. 未授权：弹窗提示：「未开启摄像头权限，可先以语音接听」，按钮「语音接听」「去设置」；点击「语音接听」：进入下一个判断，接通后本方不开摄像头；点击「去设置」：跳转系统设置
      i. 已授权，或为语音来电：进入下一个判断
   a. 4-通话占用判断：本机是否已在通话中
      i. 是：弹窗提示：「接听新通话后，当前通话将被挂断」，按钮「接听」「取消」；点击「接听」：挂断当前通话并接通新来电，本账号其他设备停止响铃；点击「取消」：弹窗关闭，回到来电界面
      i. 否：接通通话，本账号其他设备停止响铃
3. 响铃超时：响铃满 60 秒仍未接听时，来电界面关闭，本机记「未接」，主叫端记「无应答」
