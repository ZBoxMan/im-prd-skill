# 广告与个性化推荐

> 适用：PRD 涉及会话列表广告位、动态信息流广告、频道广告、广告标识与「关于这条广告」、广告频次与冷却、曝光计数、关闭与不感兴趣、举报广告、付费去广告、个性化广告与个性化内容推荐的同意和开关、定向使用哪些数据、未成年账号的广告处理时读本文件。举报形态见 SAFE-09，会话排序与置顶见 LIST-20、LIST-01，角标口径见 NOTI-07，全局搜索分区见 MISC-01，风险外链提示见 SAFE-14，服务号营销推送频次见 BOT-23，年龄判定口径与未完成年龄确认账号的默认见 AGE-07。证据见 evidence/23-ads-personalization.md。

## 基线（默认遵循，置信度高）

本模块暂无条目达到基线门槛：五家中一家不做广告，两家的广告规则多在服务端、客户端只取到文案，跨家一致的做法均不足三家直接证据，已全部放入惯例或分歧点；广告标识（ADS-01）与广告说明页（ADS-03）只有一家产品直接证据加法规旁证，法规明文不计入惯例门槛，放在分歧点并标可默认。

## 惯例（可默认，标建议）

- **[ADS-02] 广告不插入私聊与群聊的消息流**：广告只出现在一对多或独立的广告位（公开频道、动态与故事信息流、发现与目录页、独立广告卡槽），不作为一条消息插进好友私聊或群聊的聊天记录。广告位清单见 ADS-06。必定义：本需求涉及的广告位清单、加密会话与陌生人消息请求里是否完全不出广告、私密频道与公开频道是否同样投放（见 ADS-20）。｜量级：不适用｜置信度：中（两家直接证据）
- **[ADS-04] 关闭与举报是两个入口**：广告提供关闭（隐藏）入口，且关闭与举报分开：关闭只影响本人看到什么，举报进入审核。关闭是否收费见 ADS-13，关闭后的冷却见 ADS-11，不感兴趣见 ADS-12。必定义：广告菜单项清单与顺序（「关闭广告」/「举报广告」/「关于这条广告」）、菜单入口（长按或更多按钮）、关闭后的即时表现（收起、留一行撤销提示或直接消失）、举报提交后本条是否立即隐藏、已举报的再次举报提示、关闭与举报在同账号其他设备是否同步。｜量级：不适用｜置信度：中（两家直接证据）
- **[ADS-05] 举报广告**：见 SAFE-09，广告举报沿用通用举报形态；广告的原因列表可另行配置，本模块只在 ADS-04 定义举报后的本地表现。

## 分歧点（必问的问 Box，可默认的按推荐写并列清单）

- **[ADS-01] 广告标识与投放方可见**：选项 A：广告无论出现在哪个广告位，都带「广告」类标识，标识随广告一起出现、不能被单独隐藏，且与正常内容的样式可区分；投放方名称随广告可见或一点即见／选项 B：只在「关于这条广告」说明页标明是广告与投放方。推荐：A，理由：用户理解，分得清广告与正常内容；已知做广告的一家产品按 A 标识，部分上架地区的广告法规要求每条广告可识别并标明投放方（部分地区另要求标明付费方，按上架地区合规要求）。会话列表广告条目与正常会话的区分见 ADS-07。必定义：标识文案（「广告」或「赞助」）及各 locale 译文、标识在各广告位的位置（见设计稿）、读屏时是否先读出标识、投放方名称是直接显示还是在说明页、标题与正文字符上限（随 locale 变化的按 locale 分别配置）、广告带的链接数。｜级别：可默认
- **[ADS-03] 广告说明页「关于这条广告」**：选项 A：每条广告都有一点即达的说明入口（点标识或菜单项），说明页至少写清投放方、为什么看到这条广告（定向用了哪些主要参数）、本广告不使用哪些数据（如私聊、通话内容），并给出去「广告设置」的入口／选项 B：不设单条说明页，只在设置里统一说明广告规则。推荐：A，理由：用户理解与可控；「不使用哪些数据」两家直接证据，入口与投放方一家直接证据，部分上架地区要求展示定向主要参数及修改方式。必定义：入口位置与文案、说明页字段清单、付费方与投放方不同时是否分开显示、定向参数的展示粒度（国家地区、语言、所在频道或信息流、兴趣）、广告互动数据的保留期（属事实源缺口，写 {待查} 进未决项）。｜级别：可默认
- **[ADS-06] 广告位形态**：选项 A：只在一对多场景放广告（动态与故事信息流、公开频道、发现与目录页），会话列表与聊天页不放／选项 B：会话列表设独立广告卡槽（与会话行可区分、不是会话），并在一对多场景放广告／选项 C：广告以赞助会话的形式出现在会话列表（可点进、可关注，按会话规则处理）。推荐：以 ZYMIX 既有规则为准（已有会话列表广告位方案，对应 B；未确认，来自既往评审示例，写卡前向 Box 或 Figma 原稿核实）；未定时推荐 A，理由：已知产品均不在好友会话列表放平台广告，唯一例外是代理方赞助的会话；把联系人列表信息流化的产品遭用户抵制后回滚。B 与现有产品做法相反，属商业化取舍，须在交付稿写明。｜级别：必问｜定型：是
- **[ADS-07] 会话列表广告条目与正常会话的区分**：选项 A：广告条目不是会话：不计未读数与应用角标，不触发推送，不可回复，不进入会话搜索与消息搜索，不响应置顶、免打扰、归档、标为已读、左滑删除等会话操作，不参与会话排序（位置由 ADS-08 定），多选与「全部标为已读」时跳过／选项 B：广告即赞助会话，打开后进入投放方频道或服务号，按会话规则计未读并可被置顶归档。推荐：A，理由：用户理解与数据完整，广告计入未读与角标会污染用户对「有人找我」的判断；B 只在 ADS-06 选 C 时成立。角标口径见 NOTI-07，搜索分区见 MISC-01。｜级别：可默认
- **[ADS-08] 会话列表广告位的位置**：选项 A：固定在置顶会话之下的第 N 位（无置顶时为列表第 N 位），不挤进置顶区／选项 B：固定在列表最顶部，高于置顶会话／选项 C：不在首屏，滚动到一定位置后出现。推荐：以 ZYMIX 既有规则为准；未定时推荐 A，理由：用户主动置顶的会话优先级应高于广告。置顶上限与排序见 LIST-01、LIST-20。必定义：首屏加载时广告晚到是否插入（插入会让列表跳动，推荐晚到则本次不插）。｜级别：可默认
- **[ADS-09] 频次的计量口径**：选项 A：按时间计：每日曝光上限加两次曝光最小间隔／选项 B：按间隔内容条数计：每隔若干条正常内容插一条，所有正常内容之后至多一条／选项 C：按场景分口径：会话列表卡槽用 A，信息流与频道用 B。推荐：C，理由：卡槽位置固定只能按时间控频，信息流按条数更符合阅读节奏；上限值由服务端下发可调，客户端只负责遵守。必定义：计数维度（按账号还是按设备、多端是否合并）、计数清零时点（自然日按账号所在时区，见 UX-36）、上限值（以 ZYMIX 既有规则为准）。｜级别：可默认
- **[ADS-10] 曝光计数口径**：选项 A：广告全文完整进入可视区即计一次／选项 B：广告可视面积过半且连续停留不少于设定时长才计一次。推荐：以 ZYMIX 既有规则为准（既有方案按停留时长计；未确认，来自既往评审示例，写卡前向 Box 或 Figma 原稿核实）；未定时推荐 B，理由：快速滑过不计曝光，频次上限才不会被无效曝光耗尽。必定义：同一次浏览内来回滚动是否重复计、应用退到后台或锁屏时是否暂停计时、离线时曝光是否缓存补报、点击是否必须先记曝光。｜级别：可默认
- **[ADS-11] 关闭后的冷却**：选项 A：关闭单条：本条不再出现，该广告位在冷却期内（小时至天级）不再展示任何广告，期满恢复／选项 B：关闭即该广告位长期关闭，需到广告设置手动恢复／选项 C：只隐藏本条，下次刷新即出下一条。推荐：以 ZYMIX 既有规则为准（既有方案设冷却期；未确认，来自既往评审示例，写卡前向 Box 或 Figma 原稿核实）；未定时推荐 A，理由：用户关闭表达的是「现在不想看」，C 让关闭形同虚设，B 直接影响营收需另议。必定义：冷却时长、冷却是否跨设备同步、冷却期内其他广告位是否照常展示、toast 文案是否告知冷却时长。｜级别：可默认
- **[ADS-12] 不感兴趣与原因反馈**：选项 A：并入关闭：关闭后弹出可选原因（不感兴趣、重复太多、内容不适），可跳过／选项 B：「不感兴趣」单列一个菜单项，选后减少同类广告，关闭只隐藏本条／选项 C：不收集原因。推荐：A，理由：菜单项最少，用户一次操作同时表达隐藏与原因；个性化关闭时原因只影响同投放方与同类别，不用于画像。｜级别：可默认
- **[ADS-13] 去广告是否为付费权益**：选项 A：关闭单条免费，不提供付费去广告／选项 B：关闭单条免费，另提供付费订阅去除全部广告／选项 C：关闭广告本身需付费，免费用户只能举报。推荐：A，理由：用户可控，关闭入口收费会让「关闭」成为摆设；付费去广告属商业化议题，本期不涉及时不写卡；选 B 时订阅的开通、续费、取消与到期按 24 模块（开通渠道见 PTS-23）。｜级别：可默认
- **[ADS-14] 个性化的默认值**：选项 A：不做个性化：只按当前场景（所在频道或信息流）、国家地区与语言投放，无个性化开关／选项 B：默认关闭个性化，用户在广告设置中主动开启／选项 C：默认开启个性化，用户可在设置中关闭。推荐：以 ZYMIX 既有规则为准（现行隐私政策称当前不做定向广告，对应 A）；需要引入个性化时推荐 B，理由：隐私默认值从严，部分上架地区要求个性化须单独同意或可便捷关闭。个性化内容推荐（动态、频道、发现页的推荐流）与个性化广告是否同一默认值同属本议题。｜级别：必问
- **[ADS-15] 定向可使用的数据范围（是否使用聊天内容）**：选项 A：私聊、群聊、通话内容与通讯录一律不用于广告与推荐，只用场景信号（国家地区、语言、所在公开频道或信息流）与对广告本身的互动／选项 B：另使用资料与站内公开行为（关注的频道、对公开动态的互动）／选项 C：另使用未加密会话的内容关键词。推荐：A，理由：隐私与数据完整，两家已知做广告的产品都公开承诺不用私聊与通话内容；C 与端到端加密的承诺冲突。健康、宗教、政治观点、性取向等敏感类别数据在任何选项下都不用于画像。｜级别：必问
- **[ADS-16] 个性化开关的形态与入口**：选项 A：「设置」-「隐私与数据」下设「广告设置」页，分「个性化广告」与「个性化内容推荐」两个开关，广告说明页可直达，关闭长期有效、跨设备同步／选项 B：只设一个总开关／选项 C：只能在手机端修改，其他端只显示状态。推荐：A，理由：用户可理解、可恢复；广告与内容推荐受不同规则约束，合并开关会让关闭一个连带另一个。必定义：入口路径、开关说明文案、关闭后广告数量不变只是相关性降低的说明、关闭不设有效期（设有效期属反模式）；关闭后已用于个性化的数据见 PRIV-13。｜级别：可默认
- **[ADS-17] 未成年账号的广告处理**：选项 A：判定为未成年的账号不展示个性化广告与个性化推荐，只展示非个性化广告，并排除不适龄的广告类别／选项 B：判定为未成年的账号不展示任何广告／选项 C：与成年账号同样处理。推荐：A，理由：部分上架地区法规禁止对未成年人做画像广告或自动化决策营销；B 更严但影响营收，ZYMIX 最低注册年龄若为成年则主要作用于未完成年龄确认的账号。年龄判定口径与未完成年龄确认的账号按哪档处理见 AGE-07；不适龄类别清单属事实源缺口，写 {待查} 进未决项。｜级别：必问
- **[ADS-18] 点击广告的去向与外链**：选项 A：优先进入站内落地（频道、服务号、小程序或内置浏览器），外链在内置浏览器打开并显示域名，不直接拉起外部应用／选项 B：允许直接跳外部浏览器或应用商店。推荐：A，理由：可恢复（返回即回到原位）且能做风险外链提示，减少第三方追踪。风险外链提示见 SAFE-14。必定义：落地页失效（频道解散、服务号停用、链接失效）时的提示与去向。｜级别：可默认
- **[ADS-19] 动态信息流广告的插入与互动**：选项 A：首屏第一条不放广告，之后按 ADS-09 间隔插入；广告不提供点赞评论，只有关闭、举报与「关于这条广告」／选项 B：广告可点赞评论，互动只对共同好友可见。推荐：A，理由：用户理解，好友在广告下的互动会把广告变成社交内容、暴露好友行为；B 需另定互动可见范围，见 FEED-21 的互动可见规则后再议。｜级别：可默认
- **[ADS-20] 频道广告的投放条件与频道主控制**：选项 A：只在公开且订阅数达到门槛（千级）的频道投放，位于帖子流末尾或按 ADS-09 间隔插入；频道主达到一定条件可关闭本频道广告，关闭后不参与广告分成／选项 B：平台在所有公开频道统一投放，频道主不可关闭／选项 C：频道内不投放广告。推荐：A，理由：私密频道与小频道不投放，减少对小圈子的打扰，且给频道主可控性；本期不涉及分成时只写投放条件。频道公开与可发现见 FEED-12。｜级别：可默认

## 必问状态（本模块专属，补充通用状态矩阵）
- 无广告可投：拉取失败、广告已过期、库存为空、命中冷却或频次上限时，广告位是收起不占位还是保留占位；首屏加载时广告晚到是否插入。
- 账号状态：个性化关闭、未成年、未完成年龄确认、所在地区不投放、已付费去广告的账号，各广告位分别展示什么。
- 多端：关闭、冷却、举报、不感兴趣、个性化开关在同账号其他设备何时同步；桌面端与平板是否展示广告位。
- 与会话操作并存：左滑、长按、多选、全部标为已读、会话搜索、归档视图、会话分组、免打扰筛选时，广告条目是否出现、如何响应。
- 曝光与计时：后台、锁屏、来电打断、快速滑过、下拉刷新时曝光如何计；离线时曝光与点击是否缓存补报。
- 操作在途：关闭或举报时网络失败，本地是否先生效；举报提交失败的提示与重试；冷却期内切换账号。
- 落地失效：点击时广告已下线、落地频道已解散、服务号已停用、外链失效。
- 语言与地区：切换界面语言后广告语言与标识文案；不同 locale 的标题字符上限与截断；跨地区漫游时按哪个地区投放。
- 加密与私密场景：加密会话、陌生人消息请求、私密频道与群内是否完全不出广告。

## 反模式
| 泛写/错写 | 正写 | 原因 |
|---|---|---|
| 「会话列表第 N 位展示一条广告」 | 写标识、与会话的区分（未读、角标、推送、搜索、会话操作）、无广告时不占位 | 广告被当作会话处理，未读与角标口径被污染 |
| 只写「广告可关闭」 | 写关闭后的冷却、跨设备同步、关闭与举报分开、不感兴趣的去向 | 研发只做本地隐藏，下次刷新广告又出现 |
| 频次只写「每天最多 N 次」 | 写每日上限、最小间隔、计数维度（账号或设备）、清零时点、曝光口径 | 口径不同，同一上限的实际曝光可差数倍 |
| 个性化开关藏在多级菜单，或关闭后定期失效 | 「设置」-「隐私与数据」一处入口，广告说明页可直达，关闭长期有效 | 入口隐蔽与定期失效会被监管点名 |
| 「关于这条广告」只写「了解更多」 | 写投放方、为什么看到、不使用哪些数据、去广告设置的入口 | 上架地区要求展示定向主要参数及修改方式 |
| 定向数据写「根据你的兴趣」 | 列明使用与不使用的数据，明确私聊、通话内容与通讯录不用于广告 | 用户无法判断聊天内容是否被读取 |
| 未成年账号与成年账号同样投放 | 未成年账号不做个性化，排除不适龄类别，年龄判定口径引用同一定义 | 对未成年人画像广告在多地被禁止 |
| 广告标识只做了中文 | 标识与说明页按 locale 全量翻译，标题上限按 locale 配置 | 小语种下标识缺失即为未标明广告 |

## 校准样例
最易写泛的功能：会话列表广告位。只写「列表里有一条广告」会漏掉标识、与会话的区分、频次与冷却、关闭与举报、个性化与未成年处理。广告位形态已在定型时确定为会话列表独立广告卡槽；区分规则、位置、频次、曝光口径、冷却与关闭方式按推荐写成正文，卡内数值为示意；个性化默认值属隐私默认值，但推荐项写明以 ZYMIX 既有规则为准，现行隐私政策称不做定向广告，按事实源写成正文、不再提问；定向数据范围、未成年账号的处理属隐私默认值，必问，卡内留占位；不适龄广告类别清单写 {待查}。展示条件不是点击后的前置校验，按步骤写，不起判断链。

说明：
1. 适用范围：会话列表广告卡槽，位于置顶会话之下第 1 位；无置顶会话时位于列表第 1 位
2. 默认：同时满足以下条件才展示一条广告：不在关闭冷却期内、当天曝光未达 3 次、距上次曝光 ≥ 2 小时、服务端返回可投放的广告；曝光次数按账号计，多端合并，按账号所在时区的自然日清零
3. 任一条件不满足，或广告拉取失败、广告已过期：卡槽不占位，列表按正常会话排列，不显示空白或加载态；首屏加载后广告才返回时，本次不插入
4. 标识：广告卡固定带「广告」角标，角标不可关闭；读屏先读出「广告」，再读投放方名称与标题
5. 与会话区分：广告卡不计入未读数与应用角标，不触发推送，不可回复、置顶、免打扰或归档，不出现在搜索结果中；多选与「全部标为已读」时跳过广告卡
6. 曝光口径：广告卡一半以上进入可视区并连续停留不少于 1 秒，计 1 次曝光；同一次浏览内来回滚动不重复计；应用退到后台或锁屏时停止计时
7. 点击广告卡：进入站内落地页（频道、服务号或内置浏览器）；外部链接在内置浏览器打开并显示域名；落地页已失效时 toast 提示：「该内容已失效」，停留在会话列表
8. 长按广告卡或点击更多按钮，弹出菜单：「关闭广告」/「举报广告」/「关于这条广告」
9. 点击「关闭广告」：广告卡立即收起，toast 提示：「已关闭，24 小时内不再展示」；随后弹出可选原因「不感兴趣」/「重复太多」/「内容不适」，可跳过；冷却期在同账号其他设备同步生效；网络失败时本地先收起，联网后补报
10. 点击「举报广告」：进入举报原因选择，流程与消息举报一致；提交成功后本条广告立即收起，toast 提示：「已收到举报，我们会尽快处理」；无网络时 toast 提示：「网络不可用，请检查网络后重试」，提交失败时 toast 提示：「网络异常，请重试」，广告卡均保持原状
11. 点击「关于这条广告」：展示投放方名称、为什么看到这条广告、本广告未使用的数据，底部为「广告设置」入口
12. 个性化：不做个性化，只按国家地区、语言与当前场景投放，以现行隐私政策为准
13. 定向数据：{待定：是否使用聊天内容做广告定向，推荐：私聊、群聊、通话内容与通讯录一律不用于广告}
14. 未成年账号：{待定：未成年账号的广告处理，推荐：不展示个性化广告，并排除不适龄的广告类别}；不适龄类别 {待查：上架地区不适龄广告类别清单}；哪些账号按未成年处理（含未完成年龄确认的账号）与年龄确认功能的判定规则一致
注：定向数据范围、未成年账号的广告处理需确认后定稿；不适龄类别清单待合规答复后替换
