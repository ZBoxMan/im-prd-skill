# 媒体与文件

> 适用：PRD 涉及图片/视频/文件/语音发送、大小与数量上限、压缩与原图、图片拍摄位置等元数据、自动下载、媒体过期与缓存清理、发送进度与失败重传、文件风险提示。证据见 evidence/06-media-files.md。

## 基线（默认遵循，置信度高）
- **[MEDIA-01] 单文件大小上限与超限提示**：单文件有大小上限，超限时拦截并提示。必定义：上限数值与单位、图片/视频/普通文件是否分别设限、超限在选择时还是发送时拦截、提示里是否写出上限值、文案。｜量级：普通文件百 MB 至数 GB，视频发送目标数十至百 MB｜置信度：高
- **[MEDIA-02] 压缩为默认，原图/高清可选**：图片和视频默认压缩后发送以省流量，发送方可选原图/高清。必定义：默认档、切换入口、接收方能否查看或下载原图及入口是否标明文件大小、原图是否随时间过期、选原图后的流量提示、已发送媒体能否补升画质（一家产品不能）。｜量级：不适用｜置信度：高
- **[MEDIA-03] 一次多选数量上限**：单次发送图片/附件数量有上限。必定义：上限数值、超限时的处理与提示（勾选时阻止继续添加、截取前 N 个还是整体拒绝）、图片与视频能否混选、合并为相册还是逐条发出。｜量级：约 10 至 100 个｜置信度：高
- **[MEDIA-04] 媒体不可用时的占位**：媒体不可用（本机缓存被清理或服务端内容已失效）时，点击或打开给出原因提示，不留空白、不静默失败。必定义：两类原因是否分别提示（缓存被清可重新下载、服务端失效不可恢复）、两类占位文案、占位上可用的操作（重新下载、收藏、转发）、失效后聊天记录是否保留缩略信息、一次性内容到期未打开时的占位。｜量级：不适用｜置信度：高
- **[MEDIA-08] 录音手势**：按住录音、松手发送；录音中必须有取消方式。必定义：桌面与网页端是按住还是点击开始与结束、取消的手势方向与触发距离（桌面端用键盘键）、取消后的提示、录音被来电打断的结果、录音草稿是否保留、是否支持锁定后免按住（见 MEDIA-18）。｜量级：不适用｜置信度：高

## 惯例（可默认，标建议）

- **[MEDIA-06] 危险文件风险提示**：可执行文件等高风险类型，在打开或保存前提示风险。必定义：风险类型清单、提示时机（打开、预览、保存）、确认后是否继续、是否对部分类型直接禁止发送或打开、预览可能暴露网络地址时是否另行提示。｜量级：不适用｜置信度：中（两家直接证据：一家对可执行文件弹风险提示，一家给危险或可疑文件打标记；后者另有违禁文件标记，可能直接禁止，「而非一律禁止」不成立，已移入必定义；预览暴露网络地址是另一类风险，只有一家证据，只在必定义）
- **[MEDIA-05] 媒体/文件发送失败可重发**：上传中断或失败后，失败消息提供重发入口，并写明是否需要重新选择文件（源文件已被删除时无法重发）。必定义：中断后是否续传、源文件不存在的提示、重发后的进度重置。｜量级：不适用｜置信度：中（媒体专项仅两家直接证据，其余为通用失败重发）
- **[MEDIA-20] 默认发送的压缩图片不带拍摄位置等元数据**：图片按默认（压缩）方式发送时，发送端重新编码，不携带原图的拍摄位置、拍摄设备等元数据。必定义：视频默认压缩时是否同样处理；发原图与以文件形式发送时的处理见 MEDIA-19。｜量级：不适用｜置信度：中（两家开源客户端源码直接证据）

## 分歧点（必问的问 Box，可默认的按推荐写并列清单）
- **[MEDIA-07] 语音时长上限与到时行为**：选项 A：到上限自动发送并提示可继续录（一家产品，量级：约一分钟）／选项 B：到上限自动停止，进入待发送或草稿（一家产品，桌面端量级：约一小时）／选项 C：到上限自动停止并丢弃（不推荐）。推荐：A，理由：用户理解且不丢内容（语音为 IM 高频入口，上限取一分钟量级可控）。必定义：剩余倒计时提示时点。｜级别：可默认
- **[MEDIA-09] 语音转文字**：选项 A：不提供／选项 B：长按或滑动触发转写，无语音时提示未识别到语音，付费用户额度更高（两家产品，其中一家仅取到设置页标题，中置信）。推荐：A，理由：隐私（语音上传识别）且范围最小，有诉求再加。｜级别：可默认
- **[MEDIA-10] 视频消息（短视频即拍即发）**：选项 A：不提供／选项 B：提供圆形/方形短视频，限定体积与码率（量级：十余 MB），可被对方设置禁止接收，可被群管理员禁用。推荐：A，理由：单一来源，与图片/视频/语音重叠，后续再评估。｜级别：可默认
- **[MEDIA-11] 自动下载策略**：选项 A：用户可按媒体类别（图/视频/语音/文件/动图）与会话类型（私聊/群/频道）分别设大小阈值（一家产品）／选项 B：固定阈值，小文件总是下载、大文件从不下载，中间值由用户设（一家产品，量级：百 KB 以下总下载，数百 MB 以上不下载）／选项 C：仅支持「自动下载在其他设备已查看的内容」一项（国内一家主流产品）／选项 D：按网络类型（移动数据、Wi-Fi、漫游）分别勾选图片、语音、视频、文档，无大小阈值，漫游提示可能产生高额流量费，语音默认自动下载（一家产品）。推荐：D，理由：用户理解（勾选即所得），且覆盖流量敏感的蜂窝场景；各网络类型下的默认勾选集合需 Box 另行裁决。｜级别：可默认
- **[MEDIA-12] 服务端媒体保留期**：选项 A：云端长期保存，本机清缓存后可重下（一家产品）／选项 B：有限保留期，到期失效（国内主流产品，保留期官方未公开，第三方转述为数天至数十天）／选项 C：服务端仅暂存未送达内容，数周至数十天后丢弃，已送达者不再保存（隐私优先类产品；另一家产品的加密媒体在服务器保留数周，仅一次性内容场景取证）。推荐：B，理由：存储成本可控且与 MEDIA-04 占位相配；若选 A 须定义存储成本与账号注销后的清理。必定义：保留期是否按类型分档（图片、视频、语音、文件）、到期前是否提醒。｜级别：必问
- **[MEDIA-13] 本机缓存清理策略**：选项 A：仅手动清理，按类别与会话展示占用，清理后提示可重下／选项 B：A + 自动清理：按会话类型设保留时长，并设最大缓存体积，超限清理最久未用／选项 C：按消息条数或时长裁剪聊天记录，同时清媒体（隐私优先类产品，含确认）。推荐：B，理由：可恢复（媒体云端可重下）；若选 C 必须写清不可恢复。必定义：磁盘空间不足告警档位（量级：一至三档，三档仅一家产品）。｜级别：可默认
- **[MEDIA-14] 超大文件处理**：选项 A：超上限直接拒绝并提示上限（三家产品）／选项 B：超上限自动转云端分享链接，对方通过链接下载（国内一家主流产品）。推荐：A，理由：用户理解且不引入链接过期与第二套下载流程。必定义：每日发送额度是否存在、额度用尽的提示。｜级别：可默认
- **[MEDIA-15] 是否按付费分档**：选项 A：不分档（隐私优先类产品、国内一家主流产品、另一家全球主流产品，后者为中置信）／选项 B：付费提高单文件上限与传输速度，免费档限速并提示（一家产品，上限量级翻倍）／选项 C：付费提高每日额度（国内另一家主流产品）。推荐：A，理由：ZYMIX 既有规则未登记分档，不新增用户分层。选 B 或 C 时，会员到期后超出免费上限的既有内容见 PTS-25。｜级别：可默认
- **[MEDIA-16] 大视频处理**：选项 A：客户端发送前压缩到目标体积，源视频超极限不再转码，提示不支持（两家产品，量级：目标数十至百 MB，网络较慢时目标更小、分辨率更低，源极限约 1 GB）／选项 B：原样上传，服务端异步转码，转码中占位「视频处理中，可能需要数分钟」，转发待转码完成后发布（一家产品）。推荐：A，理由：弱网下失败可早发现；B 须写清转码失败的结果。｜级别：可默认
- **[MEDIA-17] 画质档位与流量提示**：选项 A：每次发送时选择是否原图（两家产品）／选项 B：全局设置「标准/高清」，高清时提示更耗流量（两家产品）／选项 C：全局默认加发送时单次覆盖，蜂窝网络下发高清弹窗确认，已发送的不能补升画质，动态与头像不适用高清（一家产品，A 与 B 的并集）／选项 D：按网络类型自动选择（本轮未取证）。推荐：C，理由：用户理解（默认省事、单次可改），且一并覆盖 A、B 两种做法。｜级别：可默认
- **[MEDIA-18] 录音锁定免按住与暂停预览**：选项 A：不提供，录音期间须一直按住，松手即发送或取消／选项 B：上滑锁定后免按住，可暂停并预览，满意再发送，或转为草稿（两家产品）。推荐：B，理由：隐私与数据完整优先，减少长录音误发与丢失。必定义：锁定入口与取消方式、暂停后草稿保留位置与时长、预览中被来电打断的结果。｜级别：可默认
- **[MEDIA-19] 发原图或以文件形式发送图片时的拍摄位置等元数据**：默认（压缩）发送见 MEDIA-20，本条只管原图与文件形式。选项 A：同样默认抹除拍摄位置等元数据／选项 B：发送前提示「含拍摄位置」，由发送者选择是否抹除／选项 C：不处理，原样发出。原图开关见 MEDIA-02，发送位置消息见 RICH-01。推荐：A，理由：隐私——拍摄位置会暴露住址与行踪，接收方查看图片不需要这类信息；取舍背景：只有一家取到直接证据（发图时有「含拍摄位置」提示与「抹除拍摄位置」入口，默认值未取证）；其余四家原图与文件形式的处理未取证，不是有反例。｜级别：必问

## 必问状态（本模块专属，补充通用状态矩阵）
- 对方已拉黑/已删除我：上传到一半被拉黑的媒体，发送结果与已上传文件的清理
- 对方已退群/已注销：对方侧已无法下载时，发送方看到的状态
- 发送中被取消：取消入口位置、已上传部分是否丢弃、是否留下失败气泡
- 多端：另一台设备已下载或已查看的媒体，本机是否同步标记；本机从未下载过的旧媒体能否从云端或其他设备拉取；其他设备无该附件时的失败提示
- 离线接收方：对方离线期间媒体的保留期；上线后自动下载是否触发
- 弱网：上传进度的呈现与超时、是否支持断点续传、切后台后的继续上传
- 权限被中途收回：群管理员在上传途中关闭「发图片/文件/语音」权限，在途消息的结果
- 对方限制接收某类消息（语音、视频消息）：被拒文案与能否改用其他类型
- 消息已被转发/引用：原媒体失效后，转发与引用卡片的展示
- 媒体已过期或被清理：占位点击后是重新下载还是提示失效
- 语音：连续播放（播完一条自动播下一条未听语音）是否提供、已听标记是否跨端同步、听筒/扬声器切换、录音中来电或切后台
- 相册：多图中单张失败，整组是否重发
- 大小口径：显示单位（MB/GB）与四舍五入规则
- 一次性内容：到期未打开的占位、备份只保留未打开的、已被另一台设备打开
- 蜂窝与漫游：发送高清或自动下载前的流量确认
- 以文件形式发送图片或视频：拍摄位置等元数据是否同样处理（随 MEDIA-19）

## 反模式
| 泛写/错写 | 正写 | 原因 |
|---|---|---|
| 「文件大小有限制」 | 写上限值、分类型是否分设、拦截时点、超限文案 | 无数值开发无法实现 |
| 「支持原图发送」 | 写默认档、切换入口、大小展示、原图是否过期 | 原图是单独的状态与存储 |
| 「文件过期不能下载」 | 区分本机缓存被清与服务端失效，分别写占位与操作 | 前者可恢复，后者不可 |
| 「一次最多选择 N 张」 | 写超限是截取还是拒绝、能否混选、合并为相册还是逐条 | 超限分支不唯一 |
| 「语音最长 60 秒」 | 写到时自动发送还是停止、倒计时提示、被打断结果、取消手势 | 到时行为是核心分支 |
| 「上传失败可重试」 | 写是否续传、源文件已删除怎么办、重发进度重置 | 媒体重发有额外失败态 |
| 自动下载只写「按网络下载」 | 写类别、会话类型、大小阈值三个维度及默认值 | 少一个维度就无法落地 |
| 「录音按住发送」 | 写取消手势与反馈、是否可锁定免按住、被打断结果、草稿保留 | 取消与锁定是核心分支 |
| 文件类型只写「禁止危险文件」 | 写风险类型清单与提示时机，区别提示与禁止 | 一律禁止会误伤正常文件 |

## 校准样例
最易写泛：在聊天中选择多张图片或视频发送。本例没有必问项：数量与大小上限、混选、超限拦截时机、相册形态、原图入口、失败重发都按推荐写成正文，卡内数值为示意，实际取值由业务定，并在交付稿「已按推荐默认」逐条列出。

说明：
1. 在相册中可混选图片与视频，勾选数量达到 20 个后其余项不可再勾选，toast 提示：「一次最多选择 20 个」
2. 勾选的单个文件超过 1 GB 时，该项不可勾选，toast 提示：「{文件名} 超过 1 GB，无法发送」，已勾选的其余项不受影响
3. 底部默认发送压缩后的图片与视频，勾选「原图」后发送原始文件；勾选至少一项后「发送」按钮亮起
4. 点击「发送」：多项合并为一条相册消息发出，每项显示上传进度；无网络时整条消息显示「发送暂停」，恢复网络后自动继续上传
5. 单项上传失败时，该项显示失败标识，点击只重发该项；源文件已被删除时，toast 提示：「文件不存在，请重新选择」
